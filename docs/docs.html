Documentation

Quick start guide and usage instructions

Installation (Linux, user-local)

git clone https://github.com/notmicrosoft2000-cmd/gnu-sorter.git
cd gnu-sorter
./install.sh          # install app + desktop + service menu + unit
./install.sh --service # also enable + start background watcher

Uninstall: ./uninstall.sh (keeps config/history). Use ./uninstall.sh --purge to remove them.

GUI Usage

  1. Add folders: Folders → Add Folder
  2. Add rule (wizard): Rules → Add Rule (extension/name → destination → review)
  3. Advanced: Rules ⋯ → Advanced rule editor (multi-extension, name/regex)
  4. Presets: Rules ⋯ → Apply preset (GNOME defaults/Photography/Code/Empty)
  5. Sort/Watch: "Sort Now" in header, toggle "Watch" for background auto-sort

CLI Usage

# List default template rules
gnu-sorter --list-rules

# Add rule to specific folder only (auto-detaches if inheriting)
gnu-sorter --add-rule quant --folder quant --root ~/Downloads

# View folder's effective rules
gnu-sorter --list-rules --root ~/Downloads

# Revert folder to shared template
gnu-sorter --attach-rules --root ~/Downloads

# Sweep once / watch / undo last
gnu-sorter --sweep
gnu-sorter --watch
gnu-sorter --undo-last 1

# Manage watched folders
gnu-sorter --add-root ~/Pictures/Inbox
gnu-sorter --remove-root ~/Pictures/Inbox
