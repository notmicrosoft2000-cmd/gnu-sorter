Funnel Flatpak repository.

This directory is the OSTree repository and the source of io.neptunepc.Funnel.flatpakrepo for the Funnel Flatpak build. The three commands below add the remote, install the app, and start it.

Install and run 
flatpak remote-add --if-not-exists funnel https://notmicrosoft2000-cmd.github.io/gnu-sorter/flatpak/io.neptunepc.Funnel.flatpakrepo
flatpak install funnel io.neptunepc.Funnel
flatpak run io.neptunepc.Funnel

The sandbox build has no tray icon and no login autostart. Funnel site · Download and requirements · Source on GitHub
