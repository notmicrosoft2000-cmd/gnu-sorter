Powerful Features

Everything you need for intelligent file organization

🎯

Per-Folder Rules

Each watched folder can have its own independent ruleset. Inherit the shared default template when you want consistency.

🧭

Split-View Editor

Folders on the left, rules on the right. Search, custom vs builtin badges, and a simple "Use default rules" switch.

🧙

Step-by-Step Wizard

Guided flow: choose extension or name match → pick destination → review. Perfect for first-time users.

⚙️

Advanced Editor

Compact power-user form for multi-extensions, name contains patterns, or raw regex matching.

📦

Quick Presets

Jump-start with GNOME defaults, Photography, Code projects, or Empty preset in one click.

🔍

Smart Search

Instantly filter rules by name, extension, or destination to manage large rule sets with ease.

🛡️

Safe & Reversible

Skips in-progress files (.part/.crdownload/.tmp), waits for stability, avoids overwrites with collision-safe renames, and supports undo.

👁️

Background Watcher

Watch folders continuously with inotify (Linux) or cross-platform watchdog. Polling fallback included.

🖱️

KDE/Dolphin Menu

Right-click "Sort with GNU Sorter" directly from Dolphin for instant sorting.

🎯

Tray Mode

Run minimized in system tray with quick actions: Open GUI, Sort now, Start/Stop watch, Quit.

💻

CLI + GUI

Use the intuitive GTK4/libadwaita interface or powerful CLI for scripts and automation.

🌐

Cross-Platform Ready

Optimized for Linux. Windows port underway with platform abstraction and watchdog support.
