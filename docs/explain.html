How GNU Sorter Works

Simple explanation of the magic behind automatic file organization

What is GNU Sorter?

GNU Sorter is a smart desktop app that automatically organizes files in folders by moving them into category subfolders based on rules you define. Think of it as your personal file clerk that sorts Downloads, Inbox folders, or any directory for you.

The Core Idea

Instead of manually dragging files around, you tell GNU Sorter:

  • Which folders to watch (e.g., ~/Downloads, ~/Documents/Inbox)
  • What to look for (by file extension like .jpg, .pdf or by filename patterns)
  • Where to put them (create subfolders like Photos/, Documents/, Comics/)

When a file appears in a watched folder, GNU Sorter moves it to the right category automatically.

How It Works Step by Step

1. You add watched folders

Tell GNU Sorter which directories to monitor. Each folder can have its own rules or share the global template.

2. You define rules

Rules match files by extension (*.cbz → Comics/) or by name patterns (*screenshot* → Photos/Screenshots/). You can use the wizard, advanced editor, or presets.

3. It waits for new files

GNU Sorter watches for new/renamed files. On Linux it uses inotify; cross-platform it uses watchdog (with polling as fallback).

4. It checks if file is "ready"

Downloads often write in chunks. GNU Sorter skips in-progress files (.part, .crdownload, .tmp) and waits for the file size to stay stable for a few seconds.

5. It finds the matching rule

For each watched folder, GNU Sorter picks the most specific matching rule (first match). If no rule matches, it goes to Needs-review/.

6. It moves safely

Creates the target folder if needed, avoids overwriting by renaming duplicates (file (1).ext), logs every move, and can undo it.

Key Concepts

Per-Folder Rules

Downloads can sort by extensions; your Comics folder can have its own rules. Folders can also "inherit" the shared default template.

Template vs Custom

The default rules.json is your shared template. When you customize a specific folder, GNU Sorter stores its rules in roots.d/ separately.

Stability Window

Prevents moving partially downloaded files. By default it waits ~3 seconds with unchanged file size.

Undo Journal

Every move is recorded in a history log. You can undo the last move(s) anytime from GUI or CLI.

Modes of Operation

GUI — Modern GTK4/libadwaita interface with split-view rules editor, wizard, and about dialog.
Background Watcher — Runs silently, auto-sorting as files appear. Can be enabled at login via systemd (Linux).
One-Off Sweep — Sort existing files in watched folders right now with --sweep.
CLI — Scriptable: add/remove rules/folders, detach/attach per-folder rules, undo, etc.
Tray Mode — Minimize to system tray with quick actions (Windows/Linux).
